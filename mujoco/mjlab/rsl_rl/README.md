# rsl_rl adapter placeholder

This folder mirrors the standard `legged_gym + rsl_rl` project layout.

The current Windows/MuJoCo training path uses Stable-Baselines3 PPO through
`minidog_rl.scripts.train_sb3`.  Native RSL-RL modules can be added here later
without changing the top-level `legged_gym/scripts/train.py` user workflow.
